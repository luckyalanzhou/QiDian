# Chrome 扩展

栖点 Chrome 扩展用于把当前网页保存到已配对的栖点实例。扩展令牌仅有新增书签权限，不会读取笔记或账号密码。

## 安装

1. 从栖点 GitHub 发行版下载 `栖点-Chrome扩展-版本号.zip` 并解压到长期保留的目录。
2. 打开 Chrome 的 `chrome://extensions`，启用“开发者模式”。
3. 选择“加载已解压的扩展程序”，选中解压后的目录。

更新时下载并解压新版到原目录，打开扩展管理页点击该扩展的“重新加载”。扩展尚未通过 Chrome 网上应用店分发，不会自动更新。

## 配对与保存

1. 使用 HTTPS 打开栖点，进入右上角头像中的“个人资料”。HTTP 仅支持本机回环地址。
   如果由反向代理提供 HTTPS，按[部署指南](deployment.md)设置可信代理地址；栖点只信任配置的代理转发协议。
2. 在“浏览器扩展”中填写设备名称并生成一次性配对码。配对码有效 5 分钟，只能使用一次。
3. 打开扩展，填写栖点实例根地址和配对码。浏览器会询问是否允许扩展访问这个实例；只授予实际使用的栖点地址。
4. 配对完成后，在任意网页点击扩展图标，再点“保存当前网页”。重复网址会提示已存在，不会新增副本。
5. 回到栖点个人资料可刷新令牌列表并撤销任一扩展令牌。撤销后扩展请求会被拒绝；“解除本机连接”只清除此浏览器保存的令牌和站点权限，不会撤销服务器端令牌。

管理员重置账号密码时会使该账号未使用的配对码和所有扩展令牌失效；重置后需要重新配对。

扩展只提交当前标签的网址和标题。服务端验证 HTTP/HTTPS URL，并将新书签写入 SQLite；只有数据库保存成功后才返回成功。
