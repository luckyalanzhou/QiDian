- **目标：** 将账号级整份 JSON 保存改为笔记、书签、分组、标签各自独立存储与同步，解除整份数据约 1 MB 的序列化上限，同时保留冲突检测和数据兼容。

- **实施约束：** SQLite 逐类保存笔记、标签关联、书签、分组、回收站与偏好；保持旧聚合读取、登录载荷和备份格式兼容。增量写入通过账号 revision 做原子 CAS，并用有限历史日志及删除标记支持同步；迁移前生成数据库副本，异常时回滚。取消整库 1 MB 应用层配额，保留单条字段校验与单次 JSON 请求 64 MiB 的传输保护（该保护不是账号累计配额）。
- **验收标准：** 各类记录可写入、删除并跨设备同步；并发冲突不静默覆盖；旧数据迁移成功且 malformed legacy data 可回滚、保留迁移前副本；旧 JSON/ZIP 聚合备份继续兼容；附件清理仍检查当前记录与历史快照；超过原整库上限的数据可保存和同步。
