# Web 界面设计

## 设计方向

以个人知识工作台为中心，优先展示笔记和书签。使用冷灰白内容背景、浅灰蓝侧栏和靛蓝操作色；深色主题使用对应的石板蓝灰色阶。成功、警告和危险状态分别保留语义色。颜色由设计变量提供，正文、辅助文字、边框和操作色保持独立。

- 桌面：稳定侧栏、固定顶栏、受控内容宽度。最近编辑、收藏、草稿和类型入口始终可达，切换页面时不改变导航结构。
- 首页：笔记和书签等权双栏，各使用一层内容面板；分区标题、创建操作、内容和查看全部各有固定位置。手机改为纵向排列，最近笔记最多展示两篇。
- 笔记：使用类型、标题、摘要、标签和日期组成的卡片；筛选与主操作分离。卡片菜单独立于打开笔记的点击区域。
- 书签：桌面保留目录与结果区，手机改为可折叠目录和单列链接卡片；整理、导入和分组能力沿用现有流程。
- 阅读：文章与目录分栏，正文保留合适行宽和段落间距；手机使用折叠目录。页面只保留一条正文阅读滚动轴。
- 编辑：保存、附件和图片保持可见，导出与删除归入笔记操作菜单。格式图标统一为 SVG，更多格式菜单按可用视口校正位置。
- 浮层：统一圆角、表单、按钮和菜单。危险操作使用红色文字及明确确认，不与主要操作争夺视觉权重。

## 样式边界

`src/styles/workspace.css` 是当前 Web 视觉与响应式布局的统一入口，通过 `index.html` 在基础样式之后加载。`src/styles.css` 放在 `foundation` CSS 层中，保留编辑器内容节点、行为状态及尚未独立整理的组件约束；当前视觉规则不再依赖反复增加选择器优先级。

桌面侧栏、手机底部导航、主题偏好、数据格式和业务接口保持现有产品约定。原型 `private_wiki_prototype.html` 保留，不参与构建。

## 验收范围

使用固定端口 `127.0.0.1:5173`，从空白本地预览建立三篇测试笔记及两个书签分组、六个链接。测试数据仅用于本轮验收，完成后清理。

验收需包含：

- 桌面和窄屏的空白、有内容、长标题、列表、阅读与编辑布局。
- 新建、实际输入、富文本粘贴、保存、收藏、搜索和类型筛选。
- 书签导入预览、确认导入、目录筛选、分组展开与整理模式。
- 手机底部导航、抽屉、更多菜单、版本信息、账号设置和深浅主题。
- 页面、卡片、SVG 与菜单的真实尺寸；检查横向溢出、内容遮挡和控制台错误。
- 全量自动化测试、源码与类型检查及生产前端构建。

浏览器响应式验收不等同于 iPhone Safari / Android 实机验证；Vite 本地预览也不证明生产 SQLite 或 Docker 部署行为。
